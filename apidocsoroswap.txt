🚀 Soroswap API
Soroswap.Finance is both an Automated Market Maker (AMM) and a DEX Aggregator on the Stellar blockchain.

It aggregates liquidity from Soroban DEXes (Soroswap, Phoenix, Aqua and Comet(TBA)), and the Stellar Classic DEX — giving you the best trade routes, liquidity tools, and real-time market data.

📋 What You Can Do
🔄 Quote – Get the best trade route between two assets with split-routing logic across AMMs and SDEX.
🧱 Build – Generate and simulate unsigned transactions (XDR) for swaps or liquidity actions.
🚀 Send – Submit signed transactions via RPC — or swap completely gasless with Launchtube.
⚡ Gasless Trustlines – Use gaslessTrustline in /quote to open trustlines for users without requiring them to hold XLM or deal with trustline setup themselves.
💰 Platform Fees – Add your own fee to user swaps with platformFee.
💧 Liquidity – Create LPs, add liquidity, remove liquidity.
💲 Price – Get real-time token prices.
🧠 Pools – View detailed pool information for Soroswap AMM.

Quote
Calculates the best price for a given swap by aggregating liquidity from multiple protocols on the Stellar blockchain.

It finds the optimal path to execute the swap through the Soroswap Aggregator, splitting the trade across several routes to secure the best rate.

⚡ Gasless Trustline Feature:
This feature lets your users open a trustline without needing to understand what a trustline is or how much it costs. Then, the /build endpoint will create the transaction with all the needed operations.

When enabled, the Soroswap API will return a quote that includes an additional swap to purchase 0.5 XLM to cover the trustline creation cost.

The quote will also include the trustline cost expressed in both assetIn and assetOut, so you can display this information to the user if desired (see the response schema for details).

query Parameters
network	
string
Enum: "testnet" "mainnet"
Network on which the operation will be performed

Request Body schema: application/json

Input asset contract address

assetOut
required
string
Output asset contract address

amount
required
integer <int64>
Expected input amount in stroops

tradeType
required
string
Enum: "EXACT_IN" "EXACT_OUT"
Type of trade: EXACT_IN = input fixed; EXACT_OUT = output fixed

protocols
required
Array of arrays
Array of protocols to aggregate liquidity from

parts	
number
Number of route splits for optimization. Higher values improve price discovery but increase latency. Max: 1000..

slippageBps	
number
Slippage tolerance in basis points (bps). 10000 = 100%, 100 = 1%, 50 = 0.5%. Default is 50 bps (0.5%)

maxHops	
number
Maximum number of hops to aggregate liquidity from

assetList	
Array of strings
Restricts intermediate tokens to a specific list. Only useful for Soroban transactions (Router and Aggregator). Not useful for SDEX.

feeBps	
number
Platform/referral fee in basis points. Splitted between platform and soroswap, fee in basis points (bps). 10000 = 100%, 100 = 1%, 50 = 0.5%

string
Whether to use gasless trustline swap. Only use this if you are sure that the user does not have a trustline for the output asset and if you have an sponsor account.

Build
Builds an unsigned XDR for a quote.

If Gasless Trustline Swap is enabled, the XDR must be signed by both the user and the sponsor.

⚡ Gasless Trustline Flow
When enabled, the transaction will include all the operations required to perform the swap, plus extra operations to:

💰 Buy 0.5 XLM — The user purchases 0.5 XLM and sends it to the sponsor wallet.
🛡 Sponsor Trustline Reserve — The sponsor wallet covers the reserve required to open the user’s trustline.
Note: The gaslessTrustline feature only works with a swap on the Stellar Classic DEX, and will be applied only to the first swap for a specific user.

query Parameters
network	
string
Enum: "testnet" "mainnet"
Network on which the operation will be performed

Request Body schema: application/json
required
Data required to build the quote

quote
required
object
The quote to build the XDR for

from	
string
The wallet address that will send the funds

to	
string
The wallet address that will receive the funds. If Gasless Trustline Swap is enabled, this is the wallet address must be the same as the from address (hence, don't provide this parameter)

referralId	
string
The referral id wallet address (required when feeBps is provided)

sponsor	
string
The wallet address that will sponsor the transaction. Only required for Gasless Trustline Swap and Soroban sponsored transactions

signedUserXdr	
string
The signed transaction XDR from Step 1 of Soroban sponsored transactions. Required for Step 2 when sponsor is provided for non-SDEX platforms.

Responses
200 XDR built successfully
400 Invalid quote data or missing required fields
428 Precondition Required - Multi-step action needed
