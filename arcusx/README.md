# arcusx — marketplace SPA

React 19 + TypeScript + Vite. App pública: [arcusx.pro](https://arcusx.pro).

```bash
npm install
npm run dev      # http://localhost:5173
npm run build
npm run lint
```

Env: ver `arcusx/.env.example` y el [README del monorepo](../README.md). Guía de agentes: [`../CLAUDE.md`](../CLAUDE.md).
