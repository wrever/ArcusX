## 🎨 IMAGEN — Qué crear en Canva hoy

**Concepto en una línea:** Dos ventanas de terminal, lado a lado — una etiquetada "San Francisco" y otra "LATAM". El código dentro es idéntico. La única diferencia: la línea de comisión al final.

**Paso a paso:**

1. **Fondo:** `#0a0a0a` (negro puro), sin gradientes ni texturas.

2. **Dos bloques terminal lado a lado (50/50):**

   **Bloque izquierdo — San Francisco:**
   - Barra de título del terminal: `#1c1c1c` con tres círculos decorativos (gris `#444`)
   - Etiqueta: `SF_DEV@remote ~ $` en gris `#555`, Space Mono o Space Grotesk Mono, 11px
   - Código (texto blanco `#e0e0e0`, 13px):
     ```
     function buildFeature(spec) {
       const result = ship(spec)
       return result
     }
     // Output: ✓ deployed
     // Earned: $1,000 USD
     // Fee (Upwork 20%): -$200
     // NET: $800.00
     ```
   - La línea `// NET: $800.00` en gris apagado `#666`

   **Bloque derecho — LATAM:**
   - Misma barra de título
   - Etiqueta: `LATAM_DEV@remote ~ $` en verde `#10dd88`, 11px
   - Código idéntico excepto las últimas 3 líneas:
     ```
     function buildFeature(spec) {
       const result = ship(spec)
       return result
     }
     // Output: ✓ deployed
     // Earned: $1,000 USD
     // Fee (ArcusX 3%): -$30
     // NET: $970.00  ✓
     ```
   - La línea `// NET: $970.00  ✓` en verde eléctrico `#10dd88`, bold

3. **Separador entre bloques:** Línea vertical de 1px, color `#222`, en el centro exacto del frame.

4. **Texto superior centrado** (por encima de ambos bloques):
   - `"El código es el mismo."` en blanco, Space Grotesk 700, 20px
   - Sin comillas dobles tipográficas — usar comillas rectas para el efecto terminal

5. **Texto inferior centrado** (por debajo de ambos bloques):
   - `La diferencia la pone la plataforma.` en gris `#888`, Plus Jakarta Sans 400, 14px
   - Pequeño logo ArcusX abajo a la derecha, blanco, mínimo

6. **Reglas visuales:**
   - Cero decoración adicional — la frialdad del terminal ES el mensaje
   - El verde aparece SOLO en el bloque LATAM/ArcusX
   - Misma fuente, mismo tamaño, mismo código — el contraste visual es solo en el NET
