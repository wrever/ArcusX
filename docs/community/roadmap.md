# ArcusX roadmap

Living plan for the platform, SDK, and settlement rail. Dates are estimates and may shift with security and partner priorities.

## Shipped

- Marketplace on Stellar (tasks, proposals, messaging)
- OAuth sign-in + wallet connect (Freighter, xBull, Pollar, …)
- **ArcusX Escrow** lifecycle (deploy, fund, approve, release, dispute)
- 2% platform fee from worker on escrow release
- Partner gateway `api.arcusx.pro` + `@arcusx/sdk`
- REST `/v1` contract, sandbox API keys, OpenAPI
- Agentic payments primitives (jobs / quotes) via SDK
- Docs site (`docs.arcusx.pro`) from the monorepo

## Now

- Mainnet readiness (audits, monitoring, fee/config hardening)
- SDK examples & partner onboarding (Instawards SOW track)
- Escrow UX polish and dispute evidence flows
- Agentic + webhook reliability

## Next

- Ratings / reputation
- Richer profiles and search
- Enterprise / white-label panels
- Stronger webhook & idempotency tooling
- Mobile-friendly flows

## Later

- Multi-asset experiments on Stellar
- Deeper analytics for partners
- Referral / growth programs
- Broader wallet and regional UX

## Principles

1. Security before feature velocity  
2. Settlement stays on-chain and non-custodial for user keys  
3. Partners integrate **one rail** (ArcusX), not a stack of vendors  
4. Public docs never expose internal settlement suppliers
