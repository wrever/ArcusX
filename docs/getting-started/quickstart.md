# Quickstart

Quick guide to start using ArcusX as a contributor or task creator. 🚀

## Introduction

ArcusX is a decentralized freelancing platform built on Stellar that connects clients with workers through escrow smart contracts. This guide will help you get started quickly, whether you're a worker looking for opportunities or a client who needs services.

## Prerequisites

Before starting, you'll need:

- An ArcusX account (free registration)
- A compatible Stellar wallet (Freighter recommended)
- Funds in USDC on the Stellar blockchain (for clients) or ability to receive USDC (for workers)
- Modern web browser (Chrome, Firefox, Edge, or Safari)

## For Workers

### Step 1: Create an Account

1. Visit the ArcusX website
2. Click "Register"
3. Choose between email/password registration or OAuth authentication (Google or GitHub)
4. Complete your basic profile

### Step 2: Set Up Your Wallet

1. Install the Freighter extension in your browser
2. Create a new wallet or import an existing one
3. Make sure you're connected to Stellar Testnet (for testing) or Mainnet (production)
4. In ArcusX, go to your profile and register your Stellar address
5. Verify that your wallet is connected to the platform

### Step 3: Explore Available Tasks

1. Navigate to the Dashboard
2. Review available tasks in the "Available Tasks" tab
3. Filter by category, difficulty, or budget
4. Carefully read the details of each task before applying

### Step 4: Apply to a Task

1. Select a task that interests you
2. Click "Apply"
3. Complete the proposal form:
   - Write a message explaining why you're suitable for the task
   - Provide a link to your portfolio (optional but recommended)
   - Confirm your Stellar address to receive payments
4. Submit your proposal

### Step 5: Work on the Task

Once the client selects your proposal:

1. You'll receive a notification when your proposal is accepted
2. The client will create and fund an escrow with the task funds
3. Begin working on the task according to the specified requirements
4. Communicate with the client through the messaging system if you have questions
5. When you complete the work, mark the task as completed

### Step 6: Receive Payment

1. Once you mark the task as completed, the client will review it
2. When the client approves and releases the funds, you'll receive payment automatically
3. Payment will be processed in 3 to 5 seconds directly to your Stellar wallet
4. A 0.5% platform commission will be automatically deducted

## For Clients

### Step 1: Create an Account

Follow the same steps as workers to create your ArcusX account.

### Step 2: Set Up Your Wallet and Funds

1. Set up your Freighter wallet following the steps above
2. Make sure you have funds in USDC in your Stellar wallet
3. If you don't have USDC, you can obtain it through exchanges that support Stellar USDC
4. Verify you have sufficient balance to cover the task cost plus the platform commission

### Step 3: Create a Task

1. Navigate to the Dashboard and click "Create Task"
2. Complete the form:
   - Title and detailed description of the task
   - Budget in USDC (this is the amount the worker will receive)
   - Category (Development, Design, Marketing, Blockchain, Content)
   - Difficulty level (Easy, Intermediate, Difficult)
3. Review the summary that shows:
   - Amount the worker will receive
   - Platform commission (0.5%)
   - Total to pay (including commission)
4. Publish the task

### Step 4: Review Proposals

1. Once published, workers can apply to your task
2. You'll receive notifications when new proposals arrive
3. Review each proposal:
   - Read the worker's message
   - Review their portfolio if included
   - Consider their experience and fit for the task
4. Select the proposal that best fits your needs

### Step 5: Create and Fund the Escrow

1. Once you select a proposal, a step-by-step process will open
2. Connect your Freighter wallet if not connected
3. Create the escrow contract (sign the transaction in your wallet)
4. Fund the escrow with the total amount (worker + commission)
5. Once funded, the worker will begin working

### Step 6: Supervise and Approve Work

1. Monitor task progress through the dashboard
2. Communicate with the worker using the messaging system
3. When the worker marks the task as completed, review the delivered work
4. If the work meets requirements:
   - Click "Accept Work"
   - Funds will be automatically released to the worker
5. If there are problems, you can initiate a dispute for resolution

## Commissions and Payments

### Platform Commission

ArcusX charges a 0.5% commission on each transaction. This commission is significantly lower than traditional platforms that charge between 10% and 20%.

### Amount Calculation

- The amount you specify when creating the task is what the worker will receive
- The commission is calculated and automatically added to the total escrow amount
- Formula: Total Amount = Worker Amount / (1 - 0.005)

Example:
- If you want to pay 100 USDC to the worker
- Escrow is funded with: 100 / 0.995 = 100.5025 USDC
- Commission: 0.5025 USDC
- Worker receives: 100 USDC

### Processing Time

Payments are processed instantly once funds are released from the escrow. Stellar transactions confirm in 3 to 5 seconds.

## Security and Trust

### Escrow System

All funds are held in an escrow smart contract until both parties agree. The platform cannot access, freeze, or hold these funds.

### Dispute Resolution

If a conflict arises:
1. Either party can initiate a dispute
2. An administrator will review the case
3. The administrator can resolve by fairly distributing funds
4. Administrator decisions are executed through the smart contract

### Cancellation and Refunds

Cancellations are allowed under certain conditions:
- Early cancellation: If the worker hasn't started, you can cancel and receive full refund
- Cancellation with work started: Requires initiating a dispute for resolution
- After completion: Tasks already completed and paid cannot be cancelled

## Tips and Best Practices

### For Workers

- Create a complete profile with relevant information
- Include portfolio links in proposals
- Communicate clearly with clients
- Deliver work according to agreed specifications
- Respond promptly to inquiries

### For Clients

- Provide clear and detailed task descriptions
- Set realistic expectations about times and budgets
- Carefully review proposals before selecting
- Proactively communicate with the worker
- Review and approve completed work promptly
