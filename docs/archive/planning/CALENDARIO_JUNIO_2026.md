**Regla de oro:** El verde solo para ArcusX. Nunca para el competidor. Nunca rojo.

### Tipografía
- **Títulos / Números hero:** Space Grotesk 900 (Black)
- **Subtítulos / UI:** Space Grotesk 700
- **Cuerpo / Copy:** Plus Jakarta Sans 400
- **CDN fuente:** `@fontsource/space-grotesk` vía jsDelivr

### Principios de diseño
1. **Un solo mensaje hero por post** — si hay dos, no hay ninguno
2. **El número es la imagen** — datos fuertes van en tamaño máximo
3. **Negativo space intencional** — no llenar el frame, dejar respirar
4. **Left-aligned o centered, nunca mixto** — consistencia por post
5. **Verde como payoff final** — el ojo llega al verde como recompensa

### Formato de posts
- **Dimensión:** 1:1 (cuadrado) para Instagram y Twitter/X
- **Fondo:** siempre `#0a0a0a`
- **Border-radius:** 0 (el recorte lo da cada plataforma)
- **Tipografía mínima en frame:** 12px — nunca menos
