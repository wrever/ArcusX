# ArcusX Documentation

Welcome to the **ArcusX** documentation! 

ArcusX is a decentralized freelancing platform that connects clients with workers through smart contracts (escrow) on the Stellar blockchain. This platform enables secure, transparent, and efficient freelance work with blockchain-based payments.

## What is ArcusX?

ArcusX is a full-stack freelancing platform that leverages the Stellar blockchain to provide:

- **Secure Escrow System**: Multi-signature (2-of-2) escrow accounts for safe fund holding
- **Blockchain Payments**: Direct XLM transfers from escrow to workers
- **Transparent Workflow**: All transactions are recorded on the Stellar blockchain
- **User-Friendly Interface**: Modern React-based frontend with intuitive UX

## Key Features

✅ **User Authentication**
- Email/Password authentication
- OAuth integration (Google, GitHub)
- JWT-based session management

✅ **Task Management**
- Create and manage freelance tasks
- Apply to tasks with proposals
- Track task progress and completion

✅ **Stellar Integration**
- Multi-wallet support (Freighter, xBull, Albedo, Rabet, Lobstr)
- Escrow account creation and management
- Multi-signature transaction workflow
- Direct XLM payments

✅ **Communication**
- In-app messaging between clients and workers
- Real-time chat functionality

## Technology Stack

- **Frontend**: React 19.0.0 + TypeScript 5.7.2
- **Backend**: PHP + MySQL/MariaDB
- **Blockchain**: Stellar (Testnet, migrating to Mainnet)
- **Authentication**: JWT + Supabase OAuth
- **Build Tool**: Vite 6.2.0
