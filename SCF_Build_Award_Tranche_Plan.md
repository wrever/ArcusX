# SCF Build Award - Plan de Tranches
## ArcusX Integration Track

### Timeline General: 6 Meses

---

## **TRANCHE #0 - Award Acceptance (10% del presupuesto)**
**Timeline:** Inmediato al aceptar el award  
**Pago:** Automático al aceptar

**Actividades:**
- Aceptación formal del award
- Setup inicial de repositorio y documentación
- Planificación detallada de entregables

---

## **TRANCHE #1 - MVP Enhancement (20% del presupuesto)**
**Timeline:** Mes 1 (4 semanas)  
**Criterio de Éxito:** MVP mejorado con features críticas adicionales, completamente funcional en Testnet

**Entregables:**
- ✅ **Features Adicionales Selectas** (pocas, enfocadas en estabilidad):
  - Sistema de Badges y Achievements básico
  - Mejoras de Mensajería (notificaciones en tiempo real)
  - Bot de Chat con Preguntas Predefinidas (soporte automatizado)
  - Analytics básicos para Admins

- ✅ **Testing y Optimización:**
  - Testing exhaustivo de todas las features existentes
  - Optimización de performance
  - Fix de bugs críticos
  - Documentación técnica actualizada

- ✅ **Verificación:**
  - Plataforma completamente funcional en Testnet
  - Todas las features probables y documentadas
  - Demo funcional disponible para revisores

**Evidencia de Completitud:**
- Repositorio con código actualizado
- Documentación de features implementadas
- Screenshots/videos de funcionalidad
- Testnet deployment activo y accesible

---

## **TRANCHE #2 - Stack Upgrade & Testnet Optimization (30% del presupuesto)**
**Timeline:** Meses 2-4 (12 semanas)  
**Criterio de Éxito:** Stack tecnológico mejorado, plataforma optimizada y lista para mainnet en Testnet

**Entregables:**
- ✅ **Migración de Stack Tecnológico:**
  - Migración parcial de Backend (endpoints críticos a Node.js/TypeScript)
  - Setup de PostgreSQL (preparación para migración completa)
  - Infraestructura mejorada (Redis para caching, optimización de queries)
  - Optimización Mobile y PWA básica

- ✅ **Optimizaciones de Infraestructura:**
  - CDN setup para assets estáticos
  - Load balancing básico
  - Monitoring y logging mejorado
  - Performance optimization (reducción de tiempos de carga)

- ✅ **Testing en Testnet:**
  - Testing exhaustivo de todas las integraciones (Trustless Work, Soroswap)
  - Stress testing de la plataforma
  - Security testing básico
  - User acceptance testing con usuarios beta

- ✅ **Preparación para Mainnet:**
  - Configuración de variables de entorno para Mainnet
  - Documentación de proceso de migración
  - Plan de rollback y contingencia
  - Checklist de pre-mainnet

**Evidencia de Completitud:**
- Código migrado y funcionando en Testnet
- Métricas de performance mejoradas (documentadas)
- Reporte de testing completo
- Infraestructura escalable implementada
- Demo de stack mejorado disponible

---

## **TRANCHE #3 - Mainnet Launch (40% del presupuesto)**
**Timeline:** Meses 5-6 (8 semanas)  
**Criterio de Éxito:** Plataforma completamente operativa en Stellar Mainnet, con usuarios reales y transacciones verificables

**Entregables:**
- ✅ **Migración a Mainnet:**
  - Deploy completo en Stellar Mainnet
  - Migración de datos de Testnet (si aplica)
  - Configuración de producción (servidores, DNS, SSL)
  - Integración con wallets Mainnet (Freighter, etc.)

- ✅ **Testing en Mainnet:**
  - Testing exhaustivo de todas las funcionalidades en Mainnet
  - Verificación de transacciones reales (escrows, swaps)
  - Testing de dispute resolution con transacciones reales
  - Performance testing en producción

- ✅ **Optimizaciones Post-Mainnet:**
  - Ajustes de performance basados en datos reales
  - Optimización de costos de transacciones
  - Monitoring y alertas en producción
  - Documentación de operaciones

- ✅ **Lanzamiento Público:**
  - Onboarding de primeros usuarios
  - Marketing básico (dentro de presupuesto permitido)
  - Documentación de usuario final
  - Sistema de soporte operativo

**Evidencia de Completitud:**
- Plataforma live en Mainnet (URL pública)
- Transacciones verificables en blockchain (Stellar Explorer links)
- Usuarios activos (métricas documentadas)
- Reporte de lanzamiento con métricas iniciales
- Documentación completa de usuario y técnico

## **Notas Importantes**

1. **Presupuesto:** Todos los costos deben ser de desarrollo únicamente (NO incluir: auditorías, marketing, legal fees, etc.)

2. **Auditorías:** Las auditorías de seguridad están cubiertas por separado por Audit Bank, no se incluyen en este presupuesto.

3. **Verificación:** Cada tranche debe ser verificable por los revisores del SCF (demos, código, métricas, transacciones on-chain).

4. **Flexibilidad:** El plan permite ajustes menores si es necesario, pero los entregables principales deben cumplirse según los criterios de éxito.
